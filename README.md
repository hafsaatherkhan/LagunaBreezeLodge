Built as a semester project for **BS Software Engineering at SSUET** — awarded **2nd Position**.

## 👩‍💻 My Contribution

This was a team project. My role was **Backend & Authentication System Developer**.

- Developed the complete authentication and user management system with role-based access control
- Implemented secure login and registration with structured user permission levels
- Built core Admin Portal functionalities — user management and booking history
- Designed and managed ~80% of the database logic and schema
- Collaborated with the team to integrate backend with the JavaFX interface

## ✨ Features

**👤 Guest**
- Browse available rooms

**🙋 Registered User**
- Create and manage personal account
- Make bookings
- View and manage booking history

**🛠️ Admin**
- Full user management dashboard
- View and manage all bookings
- Room availability and inventory control
